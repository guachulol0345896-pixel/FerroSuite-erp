# FerroSuite

ERP modular en la nube para ferreterías pyme en Colombia. Proyecto desarrollado
para la asignatura Arquitectura de Software.

## Estructura del repositorio

- `docs/` — documentación del proyecto (definición del problema, necesidad,
  pregunta problema, arquitectura de software, modelado UML).
- `diagrams/` — diagramas UML y de arquitectura del proyecto.
- `frontend/` — prototipo de interfaz web (Inicio, Inventario, Proveedores).
- `FerroSuite.web/` — proyecto base de ASP.NET Core para el desarrollo del backend.

## Avance del proyecto

**Fase 1:** definición del proyecto (problemática, necesidad, pregunta problema) y
primera versión de la interfaz (repositorio, estructura inicial y pantalla de
Inicio).

**Fase 2:** diseño de la arquitectura de software (arquitectura en capas, modelo
relacional, diagramas UML) y evolución del prototipo: las pantallas de
Inventario y Proveedores ahora muestran datos de prueba en tabla y permiten
agregar registros mediante un formulario. El prototipo todavía no se conecta a
una base de datos ni tiene la lógica de negocio completa; eso se desarrollará
en las siguientes fases.
